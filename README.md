# 📊 Estudos de Caso — FIA LabData

Este repositório é um espaço reservado para reunir e apresentar os projetos práticos que venho desenvolvendo ao longo do curso de **Analytics e Inteligência Artificial** (pós-graduação em Ciência de Dados, FIA LabData / FIA Business School).

## 🎯 Sobre este repositório

Aqui você encontra os estudos de caso resolvidos em grupo durante o curso, com foco em:

- Análise exploratória de dados (EDA)
- Modelagem estatística e Machine Learning (regressão linear, modelos regularizados, modelos baseados em árvore)
- Avaliação e validação de modelos
- Storytelling de dados e apresentação de resultados

## 📁 Estudos de caso

| Estudo de caso | Tema | Técnicas principais |
|---|---|---|
| Case Turnover | Rotatividade de colaboradores | Análise exploratória, modelagem preditiva |
| Case H — Desempenho Escolar | Previsão de nota final de alunos | Regressão linear e regressão regularizada (Lasso/Ridge/ElasticNet), validação cruzada |
| Case D — Custo em Seguro Saúde | Previsão de custo anual de segurados | Modelos baseados em árvore (Árvore de Regressão, Random Forest, Gradient Boosting e outros) |

*(cada estudo de caso vive em sua própria pasta, com notebook, apresentação e/ou relatório)*

## 🛠️ Ferramentas e tecnologias

- Python (Pandas, NumPy, Scikit-learn, Statsmodels, Matplotlib/Seaborn)
- Google Colab / Jupyter Notebook
